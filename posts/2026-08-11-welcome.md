## How this works

Every file in the `posts/` directory is a self-contained blog post:

1. The first line is an `#` heading — that's the post title.
2. A fenced `post-data` code block holds the metadata (date, tags, summary, optional cover image).
3. Everything after that is the post body, written in plain markdown.

When you push a new `.md` file to `posts/`, a GitHub Action regenerates `posts/index.json`, and the blog picks it up automatically — no build step, no CMS, no database.

## What you can use in the body

- **Bold**, *italic*, and `inline code`
- Links like [this one](https://example.com)
- Ordered and unordered lists
- Blockquotes
- Fenced code blocks with syntax highlighting
